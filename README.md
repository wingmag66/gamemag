# 🧙 Маг на тропе

Браузерная игра, в которой маг стоит на тропе и уничтожает монстров, идущих к нему справа налево, с помощью трёх заклинаний.

## 🎮 Управление

| Действие | Клавиша |
|----------|---------|
| Огненный шар | `1` |
| Ледяная стрела | `2` |
| Молния | `3` |
| Пауза / продолжить | `Esc` или `P` |
| Рестарт после конца | `R` |

Кнопки заклинаний на экране работают как альтернатива клавишам.

## 🚀 Запуск

Откройте `index.html` в браузере (можно через `file://`).

Или запустите dev-сервер:
```bash
npm install
npm run dev
```

## 📖 Описание игры

- **Маг** стоит на тропе (x=140) и защищается от монстров
- **Монстры** появляются справа и идут влево
- Если монстр доходит до мага — теряется 1 сердце
- При потере всех 3 сердец — поражение
- Игра состоит из 3 волн с нарастающей сложностью

### Заклинания

| Заклинание | Мана | Кулдаун | Урон | Эффект |
|-----------|------|---------|------|--------|
| 🔥 Огненный шар | 10 | 0.6с | 30 | — |
| ❄️ Ледяная стрела | 15 | 1.5с | 15 | Замедление 50% на 3с |
| ⚡ Молния | 25 | 3.0с | 20 | До 3 целей |

### Монстры

| Тип | HP | Скорость | Очки | Цвет |
|-----|-----|----------|------|------|
| Слизь | 30 | 40 | 10 | 🟢 Зелёный |

| Скелет | 80 | 30 | 30 | ⚪ Белый |

## 🧪 Тестовый режим

Добавьте `?test=1` к URL для отключения автоматического игрового цикла:

```
index.html?test=1
```

В этом режиме симуляция двигается только вызовами `window.game.tick(dt)`.

Параметр `?seed=123` зарезервирован для будущего использования.

## 🔌 Тестовое API

Глобальный объект `window.game` предоставляет:

```javascript
window.game = {
  start(),                 // сброс и старт игры
  reset(),                 // сброс в menu
  pause(),                 // пауза
  resume(),                // продолжить
  cast(spellId),           // 'fireball' | 'frostbolt' | 'lightning', возвращает boolean
  tick(dtSeconds),         // ручной шаг симуляции
  getState(),              // снимок состояния
  spawnMonster(type, x),   // добавить монстра для теста
  setMana(value),          // тестовая установка маны
  setMageHp(value),        // тестовая установка HP
  clearMonsters()          // удалить всех монстров
}
```

### getState() возвращает:

```javascript
{
  state: 'playing',        // 'menu' | 'playing' | 'paused' | 'gameover' | 'victory'
  mageHp: 3,               // 0-3
  mana: 100,               // 0-100
  score: 0,                // текущий счёт
  wave: 1,                 // 1-3
  cooldowns: { fireball: 0, frostbolt: 0, lightning: 0 },
  monsters: [
    { id: 1, type: 'slime', x: 820, hp: 30, speed: 40, slowUntil: 0 }
  ],
  elapsed: 0               // общее время игры в секундах
}
```

### Примеры тестов

```javascript
// Запустить игру
window.game.start();

// Заспавнить монстра
window.game.spawnMonster('slime', 500);

// Проверить состояние
console.log(window.game.getState());

// Протикать 1 секунду
window.game.tick(1.0);

// Попробовать каст
const success = window.game.cast('fireball');
console.log('Cast success:', success);

// Установить ману для теста
window.game.setMana(50);

// Очистить всех монстров
window.game.clearMonsters();
```
